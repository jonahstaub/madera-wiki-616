Home Page

Read everything here if you are an editor and are new.

Hello and welcome to "the school wiki". This is a Wikipedia inspired space where editors can make pages about different topics. Ask Miller if you want to edit.

  • Add a sources used section when you edit.
  • Do not spam, goof off, or write unnecessary things.
  • Organize topic tabs alphabetically, except this home page.
  • Write your name on your tab so editors know who made it.
  • Do not change the font or add tab emojis.
  • Add a "See" section when there are related topics.
  • Pictures are allowed only when they are related to the topic.
  • Use accurate information and credible sources.
  • Check whether a topic already exists before creating a new tab.
  • Do not abandon a tab and then make another one.
  • Do not change the featured topics.
  • Miller is the only person allowed to remove editors.
  • Please refrain from using AI because it defeats the point.
